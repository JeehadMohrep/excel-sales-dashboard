# Excel Sales Dashboard

An Excel sales dashboard project using Power Query and Pivot Charts to organize, analyze, and visualize sales data.

## Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts

## Project Objective

The objective of this project is to analyze sales data, organize the data using Power Query, and create interactive Pivot Charts to present key sales information clearly.

## Key Analysis

* Sales performance analysis
* Data transformation and cleaning using Power Query
* Pivot Table analysis
* Sales visualization using Pivot Charts
* Identifying patterns and trends in sales data
